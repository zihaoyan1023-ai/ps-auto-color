# 视觉判断与迭代

## 以画面关系作判断

先结合 [题材与风格选路](style-routes.md) 确定方向，再观察人物、事件、光线、亮度、色彩、形状、空间与气氛，选出与本图表达最相关的关系。允许多中心叙事或抽象画面，不要求唯一主体最亮。深暗可能是有效包围感，也可能遮掉信息；天空可能是重复面积，也可能表达尺度。根据照片决定，不把“暗就提、天空就裁、绿色就降饱和”写成规则。

参考照片只提供关系和方向：参考的亮暗分配、颜色分离、空间或气氛如何帮助主体？不同题材与光线的成片不能证明某个后期参数造成喜好，JPEG 也不足以反推出 RAW 配方。混合 ICC 的参考先做好显示解释；无配置时说明不确定，不据此断言色偏。

有分类样本时先做不看标签的观察，再看用户标签，寻找反例。喜欢组也可能有圆斑、亮区竞争或边缘问题；一般组也可能技术良好。依据当前用户意图选择浓郁或克制的表达，允许不同题材走不同路线。反馈按题材、光线、所选路线和具体区域解释；样本不足时保持候选，不推定各类别已有确定的偏好。单次满意不成为通用参数，其他使用者的明确意图优先。

## 参考到调色决策

先比较原片与参考的光向、软硬、天气、明暗跨度、主体材质和背景色。逆光夕阳的光线不能仅靠阴天照片调暖来复刻；可以借用主辅色关系，同时保留本图的天气和距离。使用已提供的少量相关参考即可，不为每张照片重新搜整套社媒；需要同屏比较时使用当前 CR 可用预览或有标注的参考图，不假定 Lightroom 的 Reference View 在 CR 有同名入口。[参考匹配讨论](https://community.adobe.com/t5/lightroom-classic-discussions/adjusting-image-to-be-similar-to-other-image/td-p/14525809)

围绕所选路线，用短句记录“借用的关系 → 本图位置与拟改方向 → 必须保留的差异”，例如“白水与深绿分离 → 先检查白水中间调及背景绿色明度 → 保留水丝与谷内雾”。不从参考 JPEG 反推精确色温或曲线值。

| 用户描述 | 先定位的问题 | 有证据才尝试的方向 |
|---|---|---|
| 更通透、去灰 | 偏色、黑白场、中间调、局部散射或光效叠加，哪项占主导 | 修正对应区域；保留有作用的远景低对比，不能直接等价为加去雾 |
| 更突出、更有冲击力 | 主体与背景的亮度、颜色、清晰度是否缺少差别 | 加强其中有效的关系，同时检查其他亮区或高饱和物是否抢眼 |
| 更柔和、安静 | 硬度来自整体对比、曲线、清晰度、去雾还是局部叠加 | 先回调造成过硬的部分，保留结构与自然过渡，不默认添加光效 |
| 更梦幻、发光 | 光效应来自哪里，哪些边缘与结构仍需可读 | 有依据时在对应光线或亮部附近试光效，比较观看线索与空气感的平衡 |
| 电影感、某种风格 | 具体主辅色、冷暖位置、明暗分布及高光过渡 | 选择适配本图的关系；没有参考时陈述候选理解，不自动套青橙或抬黑 |

这是一套本技能的诊断方法，不是从社媒证明的审美定律。Thomas 的实例同时展示了局部去灰思路与颜色误伤；只迁移问题定位，不采用其中固定极值、强制配置或 PS 图层步骤。[原作者案例](https://thomaskksj.tuchong.com/t/13397425/)

## 配置文件与自动起点

先读当前配置名称、可用强度、已有全局与局部调整。新图需要换起点时，可比较少量内置候选；Adobe Color、Camera Matching、Adaptive 均是候选，风光不必强制 Landscape。Adaptive 会改变显影而不移动滑块，且不宜默认和 Auto 叠加。Auto 是产生调整的一次操作，不能仅凭滑块值断言是否使用过；来源不明时记为未知，检查当前累计效果即可。已有成片续修优先在当前起点内修正；确需比较另一配置，先保留可恢复状态，检查旧曲线／蒙版的累计效果，不执行整体重置。[Adobe 配置文件](https://helpx.adobe.com/camera-raw/desktop/edit-and-enhance-images/tone-and-color/adjust-color-rendering-camera-camera.html)

## 颜色工具的分工

“颜色不舒服”先拆成色相、明度、饱和度和邻近颜色关系，再决定处理全图、色系还是对象。不同路线可以有不同色彩强度，颜色协调不等于趋同；曝光、白平衡与颜色可以往返。黑白端与曲线已有合理状态时保留，不要求直方图铺满、每处阴影可读或所有白色材质中性。

| 可见问题 | 优先考虑 | 同时检查 |
|---|---|---|
| 多数区域呈共同偏色 | 全局白平衡；混合光改用局部 | 不把夕阳、冷色阴影、彩灯或反光一律中和成白 |
| 明暗关系不成立 | 曝光、曲线或局部明暗 | 色相和饱和度不能代替亮度分离；曲线若带来过浓，当前版本可用时检查 Refine Saturation |
| 整个色系需变化 | HSL／全局 Point Color | 同色的衣物、房屋、白水反光是否连带变化 |
| 某物体内的颜色需变化 | 区域蒙版内 Point Color，或区域与颜色范围相交 | 先看色域可视化和覆盖，再看真实图像；避免颜色断层 |
| 需要按明暗分配冷暖 | Color Grading 的暗部／中间调／亮部及混合、平衡 | 不用风格色掩盖未解决的混合光偏色，也不让白水／肤色失去所需辨识度 |

Point Color 的 Range 限定受影响色域，Variance 改变所选范围内颜色差异，二者不能混为同一功能。收拢颜色只在确需统一局部颜色时试用，避免抹掉树叶或皮肤的正常变化；不可用时沿用 HSL／范围蒙版，不安装或升级。[Adobe 色彩工具](https://helpx.adobe.com/camera-raw/desktop/using/make-color-tonal-adjustments-camera.html)

## 耦合检查表

| 刚改的项目 | 必须重新观察的关系 | 可回调方向，不是处方 |
|---|---|---|
| 对比、曲线、白黑场 | 主体中间调是否过暗／灰白，高光是否失去结构 | 回到曝光、高光、黑色或曲线；用局部替代过强全局 |
| 去雾、清晰度 | 天空是否过蓝、树梢光边、水雾是否消失、暗部是否重新堵塞 | 降低强度、缩小范围，复核白平衡／曝光／HSL |
| 阴影、黑色提升 | 深暗区域能否阅读，光向与空间是否被拉平 | 区分近景遮蔽与中远景信息；避免所有区域等亮 |
| HSL、白平衡 | 叶片／皮肤／白水是否分离，是否出现色块和不自然色偏 | 复核明度与邻近色域，别只推整体饱和度 |
| 负去雾、Glow | 局部空气感是否变成全图灰膜，亮部是否扩散过头 | 重做蒙版几何与过渡，减弱叠加、复核全局对比 |
| AI 降噪、锐化 | 细叶、水流、皮肤是否蜡化或假纹理，提暗部后噪点是否暴露 | 降噪强度与锐化一起重审；不靠加锐掩饰细节损失 |
| 裁切、镜头校正、修复 | 主体尺度、边缘、蒙版位置／内容是否仍正确 | 重看覆盖，必要时更新 AI 设置；不自动删除旧蒙版 |

每次选择一组有关系的变量修改、比较，避免同时改大量无关滑块而无法判断原因。第一遍的参数是候选，不是锁定值；完整复审中应明确重新评估曝光，即使最后决定不变。

## 蒙版边缘与同色误伤

把“目标区域”和“目标颜色／亮度”分别决定。例如只减天空蓝，不能误减衣服蓝；可让天空区域与颜色范围相交，而不是用 Add 扩大选区。先看覆盖，再隐藏覆盖看调色。[Adobe 蒙版](https://helpx.adobe.com/camera-raw/desktop/edit-and-enhance-images/masking-and-local-adjustments/masking.html)

光边或接缝出现时，单独暂时隐藏可疑蒙版／效果定位贡献，确认后恢复或回调；若问题在全局清晰度、去雾或配置文件中，别只修蒙版。检查树梢、发丝、山脊、天空与水面的交界，必要时减强度、修 Add／Subtract／Intersect，或调整渐变几何。当前版本若提供蒙版 Feather／Edge，可实测软化或收缩／扩展；不要把“羽化越大越好”当规则。分别看适屏与 100%，防止补出另一圈光边；不堆新蒙版去抵消未定位的旧问题。

## 雾气、渐变与新光效

- 区分近景对比、远处空气感、水雾、天空自身散射和后期灰膜。保留有作用的距离，不把所有柔和区域都“清晰化”。
- 径向蒙版可收窄／加宽、拉长、移动、旋转和改变羽化。线性渐变可调整角度与过渡长度。先看覆盖再看真实效果；收窄范围可能比继续增加强度更有效。
- 范围蒙版按像素条件选取，未必等于语义对象。硬分界、色阶斑块出现时检查范围与过渡，必要时换成平滑渐变或语义选择。
- Glow 可比较关闭、适中和较强几个有意义的状态，再选择；不必穷举所有样式。漫射、光华与光晕按当前版本实际名称识别。该工具可强调已有亮部气氛，不能据此声称恢复了现场实际雾量。
- 共享的 Glow 样式／范围／扩散／暖色与局部强度分开记录，全局强度为 0 仍可能有局部发光。[Adobe Glow 说明](https://helpx.adobe.com/camera-raw/desktop/edit-and-enhance-images/tone-and-color/vignette-grain-effects-camera-raw.html)

## 前后比较与强度收敛

比较时保持同一构图、缩放、背景和 SDR／HDR 显示条件；若正在评估裁切变化则明确例外。标清 CR 起点、本组调整前和当前候选，截图不得把覆盖色、剪切提示或界面缩放差异混入结果。

先区分路线不合适与同一路线的强度不合适。前者回到选路，比较能表达不同情绪的候选；后者才围绕强度收敛。换路线仍从可恢复状态出发，不重置原有编辑，也不默认导出多版。

若在“太平”与“太浓”之间来回试，可在已确认的可恢复状态内比较较弱与较强候选，选定后再做一项针对性回调，不要求每张图导出多版本。更亮或更浓本身可以符合意图，但要指出主体、色彩分离或气氛为何更合适；必要时在 CR 内用可撤回的临时候选区分曝光变化与风格变化，结束后恢复选定状态，不把亮度强制拉齐当永久调整。

## 从社媒学习时的证据边界

区分实际读取的正文、作者简介、已观看片段、完整视频和搜索摘要。原作者的具体画面与失败反馈用于提出试验假设；点赞、教程热度和评论多数不能验证当前照片。软件能力与版本机制核对 Adobe 官方说明和本机 UI，不照抄不明单位、超出范围的数值，也不把旧版操作顺序固化。广告、预设购买和外部下载不进入执行步骤；参考图仍受当前任务授权约束。

## 从现有测试提炼的反例

两张不同光线照片的迭代说明：原来觉得“温和自然”的处理可能不够突出；将阴影、负去雾和局部光华叠加后，也可能整体偏雾。不能由一次独立评审说“无明显副作用”推断用户满意。

尚未执行或验收的反馈数值只能作为候选；没有明确单位以及是增量还是最终值时，不能写成通用默认值或下一张图的自动配方。实际续修需要采用时，应结合当时参数明确记录解释，再进行前后审阅。

## 轻量对抗复审

给评审当前图、用途及所选路线的表达目标，要求指出最有影响的问题、具体位置与判断依据；如提供前后图，准确标注阶段，不能用机内 JPEG 冒充 CR 起点。

审阅重点：主要视觉关系与所选路线是否成立？需保留的光线、结构与气氛有没有破坏？局部效果是否可定位、边缘是否自然？新增问题是可见技术缺陷还是风格取舍？不以浓郁路线的强对比要求柔和路线，也不把所有路线评回中性外观；没有证据可以不提出修改。

收到批评后回到原图检查，记录接受、部分接受或不采纳的理由，再做针对性回调和复审。多个同模型评审并非统计独立专家；用户认可仍单列。记录自己无法观察的项目，例如仅看预览无法判断完整 RAW 高光余量。
